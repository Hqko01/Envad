# Envad - Free Inventory Tracking App

> **"Simplify warehouse management with a free inventory tracking app."**

Envad is a free inventory tracking application designed to eliminate complexity in warehouse and inventory processes, making management fast, clear, and efficient for everyone.

---

## 🚀 Key Features

* **1. Real-Time Product & Inventory Tracking**
  * Product profiles with SKU, barcode, unit types (pcs, kg, etc.), and pricing.
  * Live stock quantity tracking and status monitoring.

* **2. Inbound & Outbound Management**
  * Record purchases, sales, damage/waste, and returns instantly.
  * Comprehensive transaction audit log for every stock movement.

* **3. Critical Stock Alerts**
  * Automatic dashboard alerts and notifications when items fall below set threshold levels.

* **4. Reports & Inventory Analytics**
  * Total inventory valuation, turnover rate analysis, and top-performing product reports.

* **5. Multi-Warehouse & Location Support**
  * Manage multiple warehouses/branches, track shelf/aisle locations, and process inter-warehouse transfers.

* **6. Barcode & Scanning System**
  * Generate automatic barcode/QR labels and utilize mobile or web camera scanning for instant inventory checks.

* **7. Supplier & Customer Management**
  * Maintain supplier and customer profiles with linked historical transaction logs.

---

## 🛠 Tech Stack

* **Frontend:** React / Next.js
* **Backend:** Node.js (Express / NestJS)
* **Database:** PostgreSQL + Prisma ORM
* **Authentication:** JWT / NextAuth.js
